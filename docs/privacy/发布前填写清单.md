## §2 ⚠️ 两条"声明与代码不一致就必然失败"的实测（本项目真机踩过）

| 事实 | 出处 | 对填写的要求 |
| :-- | :-- | :-- |
| 未在后台声明时，`wx.chooseMedia` **必然失败**：真机报 `chooseMedia:fail api scope is not declared in the privacy agreement` | `utils/privacy.js` 注释（2026-09-15 真机实测） | 后台**必须**声明相册 |
| VisionKit `VKSession` 要的是**摄像头**类型；只声明相册时真机 `session.start` 返回 **errno=112**（接口未在隐私协议中声明） | `utils/privacy.js` 注释（2026-09-17 RCA`_visionkit-112`） | 后台**必须**声明摄像头；**"声明一次管所有隐私接口"是错的** |

⇒ 结论：**相册与摄像头两项都要填**，缺一项对应功能就在真机上不可用（且不是崩溃，是静默降级为"手工填写"）。
