# 用"锚点前缀"做插入，会把锚点那一行吃掉（同一类错犯了五次）
现象：想在某行**前面**插一行，我把 `old_string` 写成那一行的**前半句**、`new_string` 写成"新行 + 前半句"——结果这是**整段替换**语义：没写进 `new_string` 的后半句就没了，被吃掉的行尾黏到新行末尾，整张表跟着错位。
四次实例（2026-09-19 同一天，文中 `docs/...` 路径都在 **v1 树** `../expresseage_college/`；⚠️ 迁入 v2 时的澄清：`docs/archive/2026-09-19-multi_code/SCOPE.md` **v2 树内不存在**，而 `docs/registry/APIS.md` 与 `docs/TECH_DEBT.md` 在 v2 是**同名不同物** ⇒ 别拿 v2 的同名文件去对这条）：`docs/pool/IDEAS.md` 的站点名归一行 · `docs/registry/APIS.md` 的 `pickqueue.startQueue` 行与 `parse.parseParcelText` 行 · `docs/TECH_DEBT.md` 的 TD-042 行 · `docs/archive/2026-09-19-multi_code/SCOPE.md` 的 M5/M6 行（**第四次的计数由 24 审查独立核出**——我自己的卡片当时写着"三次"，连计数都错，正好是这张卡要防的那类错）。第五次见下面补记。
根因：把 edit 当成"插入点"用。它没有插入语义，**只有"这段文字换成那段文字"**；锚点只写一半，就等于声明"那一半我不要了"。
修法（立刻见效）：插入新行时 **`old_string` 与 `new_string` 都必须包含锚点整行原文**（`new_string` ＝ 新行 + 锚点整行）。改完**数一遍结构**：表格类文件用 `($_ -split '\|').Count` 分组看列数，出现"独一份的列数"就是错位行（本次即靠它确认 TD-040 的 9 段是单元格内转义 `\|`，不是缺陷）。
下次定位：改文档表格/清单后"某行后半句跑到别的条目里"；一次编辑**看起来成功**，但 diff 里出现意料之外的删除计数（`1 deletion` 往往就是被吃掉的那半行）。**表格类文件尤其危险**：错位后判据仍然全绿（函数名还在表里，`audit-codes` 的对帐照样通过）。
同族：`2026-09-11_变异体卫生.md` · `2026-09-19_相对路径喂给NET静态方法会读空.md` · `2026-09-25_自述范围大于diff.md` —— 都是"操作看着成功、落盘的不是我要的"。
**补记（2026-09-24 · v2 波 5 r3 装配，第五次；换了项目、换了工具，同一个错）**：给 `CHANGELOG.md` 的"r2 重审"条目前插两条，`old_string` 只写了那一行的**前半句** ⇒ 后半句（含报告路径）被吃掉并黏到我最后一条新行末尾；`grep` 才发现"r2 重审"整条不见了。
**补记的放大机制（新发现的一种）**：为绕开 shell 引号，我把待插文本走环境变量传入，而 `printf` 遇到文本里的 `%`（"100% 失效"）当场报错 ⇒ 变量被截断，node 还是跑了，落盘的是**半条目的残行**。同一次操作里"吃掉一行 + 多出一行残文"两个故障叠在一起，比单纯的丢行更难发现——因为**条目数看起来是对的**。
两条立刻可用的自检：① 插入后 `grep -c "^- "` / 列数分组比**前后计数**，光看"有没有变多"不够，要**逐条比首字前缀是否仍唯一**（残行的特征正是"同一条开头出现两次"）；② 文本含 `%`/引号时一律改用**写文件 + 按路径读**，不要走 shell 变量（v2 后续两次 CHANGELOG 追加都用这个方式，没再踩）。
**补记二（2026-09-25 · v2 改判 N2 装配，第六次；同一个坑换了方向）**：这次不是"插一行吃掉锚点"，而是**拿一条只读到一半的长行当前缀锚**（读文件时被截断到 230 字符，我没回头读全就动手）⇒ 替换后**旧行的残渣接在我的新文本尾部**，长成 `…RESEARCH.md` §6.2s/specs/20260923_chat_pick/RESEARCH.md`。`。发现方式：改完立刻 `node` 打印该行**末 90 字符**（不是打印前 230 字符——那正是我上当的原因）⇒ 所以前面那条修法要加一句硬约束：**锚点行必须来自一次"读全"的输出**；长行改动后**看行尾**、别只看行首，并按"反引号闭合后又跟路径片段 / 同名路径在一行里出现两次 / 句末标点后接裸路径"三条特征扫一遍粘连残渣。
