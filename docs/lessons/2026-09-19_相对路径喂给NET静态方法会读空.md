# 相对路径喂给 .NET 静态方法 → 读到空，写回就把文件截断

现象（expresseage_college 2026-09-19）：改 `gate.ps1` 的 BOM 时，一段脚本把它从 3888 字节写成
**3 字节**（只剩 BOM）——`gate.ps1` 当场报废，靠 `git checkout -- gate.ps1` 才恢复。
根因：① `[IO.File]::ReadAllBytes('gate.ps1')` 用的是**进程当前目录**、**不吃 PowerShell 的
`Set-Location`** → FileNotFound、`$bytes` 为 `$null`；② 写回那步**没判断"读成功了吗"** → 空内容照样
`WriteAllText()` → 文件被截断（错误被 stderr 淹没，控制台还先打印了"已补 BOM"）。
修法：① .NET 静态调用一律喂**绝对路径**（`Join-Path` 之后再传）；② 写回前加**体积哨兵**
`if($b.Length -lt 100){ throw }`；③ 改前确认文件在 git 里干净，出事 `git checkout -- <file>` 秒恢复。
下次定位：**文件突然只剩几字节 / 只剩 BOM** → 先怀疑"写回脚本读到了空"，别再跑第二遍。
同族：`2026-09-11_递归删除穿透.md`（破坏性操作缺少前置校验）；同族**再犯**（第二次不是截断而是
静默跳过并打印"全绿"）见 `2026-09-20_变异脚本静默空跑.md`。
