# 2026-10-28 · 默认转发图=页面截图；朋友圈落地=单页模式（无登录态）

- 现象：给 19 个业务页加 `onShareAppMessage` 后，若不给 `imageUrl`，微信默认**截当前页面顶部**做卡片配图——订单/详情页会把取件码/宿舍/尾号截进转发卡片（违反 CONTRACT §11「L3 不进分享卡片」）。
- 现象：`onShareTimeline` 打开的是**单页模式**（scene=1154）——无登录态（`wx.login` 不可用）、**不允许跳转任何页面**、云资源需未登录访问、本地存储不共享、只能右上角菜单触发、**不能自定义落地 path**；给订单/详情页挂朋友圈 = 打开即空白/报错。
- 教训：分享类"平台默认行为"必须逐条按官方文档核（默认配图来源 / 落地页能否带参 / 生命周期能力差异），否则"功能有了"反而制造 L3 外泄或空白落地。
- 落地：显式中性封面 `assets/share/cover*.png`（禁页面截图）；朋友圈只给 role/home/help 三页；`app.js` 识别 scene=1154 跳过云启动；`tools/check.js` #33 + `tools/selftest-share.js`（182 断言）把「页面自拼卡片 / 页面层封面路径 / 会话禁分享 / 单页模式识别」钉住。
