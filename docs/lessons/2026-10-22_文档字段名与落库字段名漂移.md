# 2026-10-22 · 文档字段名与落库字段名漂移（exception.reportedAt vs exception.at）

- 现象：批 7 文档写 `partner.stats` 按 `exception.reportedAt` 聚合，但 DATA_MODEL §2.5 字段表与 `order.reportException` 实际落库字段是 `exception.at`；照文档实现会让异常统计恒 0，且假数据按文档新词造会一起错。
- 根因：写聚合口径时引用了"更自然"的字段名，没有回查字段表与写入点；文档新增段没有被 check-docs 的字段一致性判据覆盖。
- 处理：实现 `exception.at` 优先、`reportedAt` 兼容兜底；Lead 回写 DATA_MODEL §7.4 批 7③ 统一字段名；`selftest-partner-customers` C 组锁异常计数，变异电池 M3 去掉区间过滤即红 10+ 项。
- 教训：①聚合口径必须写明"取哪个字段的哪个时间戳"，并与字段表/写入点逐一对照；②测试假数据按真实落库字段造，不要按文档新词造；③发现漂移先回写文档再（或同批）改代码，避免下一批照错文档实现。
