# 教训 · "我转录的样本" ≠ 真机输出：首轮真机验收就是这样被打回的
**发生**（v1 · 2026-09-17）：解析规则按"截图逐行转录"的样本写出来，**真机首轮验收被打回** —— 真机 VisionKit 把**整屏输出成一整行**，而我的样本是**按截图分行**的 ⇒ 规则在样本上全绿、在真机上全错。
**根因**：转录时人会**无意识地"整理"**输入（分行、补空格、规整标点），而解析规则恰恰吃这些格式差异 ⇒ 样本已经不是我声称的那个东西了 —— 等于拿**我自己造的样本**当判据基准。
**规矩（v2 起生效）**
1. 样本进仓前**照抄真机/工具原文**（含换行形态），不许"整理"；抄不了就必须标"来源 = 人工转录"。
2. 每条样本语料都带**来源标注**：`真机原文` / `工具输出` / `人工转录`；**转录样本只配当探索用，不当判据基准**。
3. 拿到真机原文后**立刻替换**转录版，并把两者的差异（本例：一整行 vs 多行）写成一条钉子。
**下次定位**：本地全绿、真机全错，且差异集中在"换行 / 空格 / 标点"这类格式；样本目录里没有任何来源标注。
