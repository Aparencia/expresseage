# 对陈旧产物测量 = 读数无效；judged=true ≠ 读数有效
现象：构建/测试读数与源码对不上；`Copy-Item` 还原文件保留 mtime ⇒ cargo 回放陈旧警告（假读数，A-5）；陈旧产物照样 `judged=true` 且 `pass=true`（B-37）。
根因：测量对象是旧 dist/未重建产物；测试运行器缓存（vitest 4 把缓存写进 node_modules，`--no-cache` 不够）让"改→跑→还原"给假红（#28）；mtime 被误当时点证据。
修法（实测）：测量前重建；**懒侧数字必须与产物内容哈希绑定**（内容指纹变了读数才算数，batch08-groundwork-2.md:37）；时点证据用 git log/命令输出时间戳，mtime 不可当时点载体（P-37）。
下次定位：读数与源码矛盾；性能/体积/覆盖率声明；变异体实验读数诡异。
证据：batch01-deletions.md:130（A-5）· batch04-primitives.md:41（#28）· batch08-groundwork-2.md:37
