# 变异脚本"静默空跑"：什么都没做，却打印"全绿"

现象（expresseage_college 2026-09-20 转发任务）：变异脚本里相对路径读文件 → `$null` → `.Replace()`
抛在子表达式、`$ErrorActionPreference` 默认 `Continue` → 脚本跑完只打印"变异未生效"，**末尾那句
"还原后全绿复验"照样打印** ⇒ 看着像跑过了，实际一次变异都没做（比"截断文件"更毒：那个看得见）。
同族 `2026-09-19_相对路径喂给NET静态方法会读空.md`（.NET 静态调用不吃 `Set-Location`）。
修法五条（每次变异都要回执，别只靠"输出看起来正常"）：1. 开头 `$ErrorActionPreference='Stop'`；
2. 路径一律**绝对路径**；3. 生效检查 `if ($mut -eq $orig) { 报警并 return }`；
4. 还原后**逐字节比对**才算收工；5. **锚点换行必须与文件真实换行一致**（本批踩了三次：
工作区 LF 而脚本写 CRLF ⇒ 静默不匹配）；最稳的还原是 `git checkout -- <file>`，不是字符串替换。
下次定位：**"未生效"或输出异常干净** → 先查①路径②`$ErrorActionPreference`③换行，别急着下"判据有效"。
