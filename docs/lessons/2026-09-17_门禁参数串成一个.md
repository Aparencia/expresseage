# 门禁参数被串成一个字符串 → 全量假红（仪器 bug，非越界）

现象（2026-09-17）：按 23 卡文档写 `powershell -File gate.ps1 -ScopeFiles "a.js","b.md"` → **除第一个文件，其余全被判"越界"**（假红）。
根因：`powershell -File` 是原生调用边界，PS 5.1 把逗号数组**压成一个字符串**；范围校验拿整串去比单个文件名，必然不命中。
同族另三种用法（2026-09-19 修复批实测，**全都伪装成"代码越界"**）：
　① 只传"本批"清单 —— gate 比的是 `git diff --name-only <Anchor>..HEAD`（**锚点以来累计**）→ 既往批次全判越界；
　② 传数组变量 `-ScopeFiles $arr` —— 在边界被拆成多个位置参数，后几个绑到相邻参数（实测报 `Cannot convert … to Int32`）；
　③ **提交前跑** —— `anchor..HEAD` 为空 ⇒ 范围校验整段跳过 ⇒ 退出码 0 是**空绿**（比假红更危险）。
修法：脚本入口就地 `$ScopeFiles = $ScopeFiles -split ','` 归一；调用侧**传单个逗号串**、**先提交再跑**。
　附：改 `.ps1` 会写出无 BOM 的 UTF-8 → PS 5.1 按 GBK 读即语法崩 ⇒ **改完先跑 `check.ps1` 再跑它本身**。
下次定位：门禁"全量报错"看入参；门禁报**绿**时先确认它**真的看了文件**（`$changed` 为空或被过滤规则滤光 = 空绿）。
