# 隐私接口未声明 = API 直接失败（不是代码缺陷）
现象：真机点"选图"报 `chooseMedia:fail api scope is not declared in the privacy agreement`（expresseage_college 2026-09-15 真机实测）；同一份代码在声明隐私指引前**必然失败**，改代码无用。
根因：2023-09-15 起小程序调用隐私接口（相册/摄像头/位置/麦克风等）前，主体必须在微信公众平台完成《用户隐私保护指引》声明；未声明则平台直接拒绝该 API。
修法：① 人：公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引 → 声明对应信息类型 + 具体用途 → 提交生效（后台路径以实际界面为准）② 代码：用 `wx.getPrivacySetting` / `wx.requirePrivacyAuthorize` 处理授权，并**为拒绝授权准备降级路径**（本项目降级 = 手工输入站点/取件码）③ 排查顺序：先问"这个 API 要不要隐私声明"，再怀疑代码。
下次定位：隐私类 API 首次真机调用即失败、devtools 或他人机器上却正常；报错串含 `privacy agreement` / `api scope`。
