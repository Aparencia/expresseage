## 2. 微信公众平台操作步骤（按序点）

> 入口名称以当前控制台实际显示为准（「管理 → 版本管理」或「开发管理 → 版本管理」均可找到开发版本）。

1. 打开 <https://mp.weixin.qq.com>，用主体账号管理员微信扫码登录。
2. 「管理 → 版本管理」（或「开发管理 → 开发版本」）→ 找到步骤 2 上传的 **v2.1** 开发版本 → 点「提交审核」。
3. 按 `01_*` §1 逐字段填写：
   - 版本描述 → `01_*` §2.1（字段短时用 §2.2；字数以后台计数为准）；
   - 功能页面 → 从 `01_*` §1.1 逐条「添加」并保存（最多 10 条；全量 33 页，团队页经「服务配置 → 我的团队」进入，不在 10 条直达路径内）；
   - 测试说明/审核说明 → `01_*` §3.1（字段短时用 §3.2）；
   - 备注 → `01_*` §4；
   - 联系方式 → `{{联系方式}}`（与 `docs/privacy/隐私保护指引.md` 同一值）。
4. 进入「功能页面」配置：逐条粘贴 `01_*` §1.1 的 10 个页面路径 → 保存 → 回到提审页确认已带上。
5. 隐私接口自检：按平台提示查看检测清单，确认 `privacy_list ⊆ setting_list`；缺项先回后台补声明（约 5 分钟生效），不带着缺项提交。
6. 上传补充材料：图片按 `02` §1 顺序上传（示意图 4 张 + 真实页面截图，先精选 8 张再追加）；说明文字用 `01_*` §5/§6；**双机录屏按 `02` §7 #15 附上**。
7. 加急审核（可选）：后台入口与额度以实际为准；理由用 `01_*` §7.1，不承诺审核结果。
8. 点「提交审核」→ 记录：提交时间、版本号 v2.1、提审单号、状态（截图存证，记为 E17 的一部分）。
9. 审核期间纪律：不改提审版本的代码、不改隐私声明、不换体验版、不动云函数大版本；如需修改，撤回后按 §3 重走。

### 4.2 发布操作

1. 后台「版本管理」→ 审核通过的 v2.1 版本 → 点「发布」（平台提供分阶段发布时可按比例放量）。
2. 灰度分批按 RUNBOOK §10.1：G0 体验版 → G1 分阶段（平台支持时）→ G2 全量；**没有观测读数不进入下一批**，判停阈值与处置见 RUNBOOK §10.3。
3. 发布后 30 分钟：用真实设备打开小程序，按 §4.3 冒烟；看 `api` 云函数错误率与超时是否正常。
4. 记录：发布版本、发布时间、发布形态（全量/分阶段）、首轮读数（截图存证）。

### 4.3 发布后 30 分钟冒烟（含新功能）

1. 冷启动、隐私弹窗（v1.10 文本）、身份选择、顾客首页「下单」入口正常。
2. 顾客下单（可无截图手填）→ 兼职接单 → **逐件取件** → 送达 → 顾客详情看到件级进度。
3. 底部伪 tab：首页/订单/取件码/我 四格可切换；取件码页只显示本机清单、无分享入口。
4. 兼职端：工作台「今日订单流水」/多站点分组正常；客户页筛选器可用；服务配置 →「我的团队」可进入（主兼职发子码、名额显示）。
5. 双机可用时：转派发起 → 待接收区 → 确认；顾客端看到实际履约兼职编号、看不到其头像/昵称。
6. 后台：总览/审计可打开；邀请码列表含 `kind`/`issuerPartnerNo`；识别失败复核可临时查看原图并留审计。
7. 异常处理：任一环节 5xx/白屏 → 立即停止放量，按 RUNBOOK §10.4 回滚（批 26/27 回退 `api` 即可，索引可保留）。

## 6. 审核后清理

1. **邀请码**：后台把本批未使用的 `DEV` 审核邀请码整批作废（一码一用用掉的不用重复处理），截图留证（E7）。
2. **团队子码**：演示期间主兼职生成的子邀请码，按 `batchId` 在团队页「作废本批」；已激活的演示子队员在团队页移除（移除后对方停用，如需恢复由开发者执行）。
3. **测试账号与测试数据**：后台「切换账号 → 测试账号」→ `deleteTestAccount`（先 dryRun 看计数）或 `purgeTestData`（dryRun → confirm）；核对审计前后条数（E18）。
4. **演示数据**：本批为演示造的识别失败记录，按复核页「忽略」或到期清理；转派/团队演示产生的订单与邀请记录按测试数据处理，不保留真实用户信息。
5. **截图与录屏**：含真实值的原片只放本地受限目录；入仓图片保持打码状态。本机取件码清单属用户设备数据，无需也无法由后台清理。
6. **归档**：把本表状态列补齐（人填）；发布结论、驳回处置、清理结果由 Lead 统一回写 `STATE.md`/`CHANGELOG.md`（本文件不自行登记）。
