## 2. 微信公众平台操作步骤（按序点）

> 入口名称以当前控制台实际显示为准（「管理 → 版本管理」或「开发管理 → 版本管理」均可找到开发版本）。

1. 打开 <https://mp.weixin.qq.com>，用主体账号管理员微信扫码登录。
2. 「管理 → 版本管理」（或「开发管理 → 开发版本」）→ 找到步骤 1 上传的开发版本 → 点「提交审核」。
3. 按 `01_*` §1 逐字段填写：
   - 版本描述 → `01_*` §2.1（字段短时用 §2.2）；
   - 功能页面 → 从 `01_*` §1.1 逐条「添加」并保存（最多 10 条）；
   - 测试说明/审核说明 → `01_*` §3.1（字段短时用 §3.2）；
   - 备注 → `01_*` §4；
   - 联系方式 → `{{联系方式}}`（与 `docs/privacy/隐私保护指引.md` 同一值）。
4. 进入「功能页面」配置：逐条粘贴 `01_*` §1.1 的 10 个页面路径 → 保存 → 回到提审页确认已带上。
5. 隐私接口自检：按平台提示查看检测清单，确认 `privacy_list ⊆ setting_list`；缺项先回后台补声明（约 5 分钟生效），不带着缺项提交。
6. 上传补充材料：图片按 `01_*` §7.2 顺序上传（示意图 4 张 + 真实页面截图），说明文字用 `01_*` §5/§6。
7. 加急审核（可选）：后台入口与额度以实际为准；理由用 `01_*` §7.1，不承诺审核结果。
8. 点「提交审核」→ 记录：提交时间、版本号、提审单号、状态（截图存证，记为 E17 的一部分）。
9. 审核期间纪律：不改提审版本的代码、不改隐私声明、不换体验版、不动云函数大版本；如需修改，撤回后按 §3 重走。

## 6. 审核后清理

1. **邀请码**：后台把本批未使用的审核邀请码整批作废（一码一用用掉的不用重复处理），截图留证（E7）。
2. **测试账号与测试数据**：后台「切换账号 → 测试账号」→ `deleteTestAccount`（先 dryRun 看计数）或 `purgeTestData`（dryRun → confirm）；核对审计前后条数（E18）。
3. **演示数据**：本批为演示造的识别失败记录，按复核页「忽略」或到期清理；不留真实用户信息。
4. **截图与录屏**：含真实值的原片只放本地受限目录；入仓图片保持打码状态。本机取件码清单属用户设备数据，无需也无法由后台清理。
5. **归档**：把本表状态列补齐（人填）；发布结论、驳回处置、清理结果由 Lead 统一回写 `STATE.md`/`CHANGELOG.md`（本文件不自行登记）。
