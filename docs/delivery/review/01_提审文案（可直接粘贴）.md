# 01 提审文案（可直接粘贴）· 审核说明 / 版本描述 / 备注 / 加急理由

> 定位：把提审页面要填的文字**逐字复制**进来的底稿；只写可公开的表述，不写实现细节、不写真实值。
> 执行人：**用户**（小程序主体账号持有人、提审操作人）。agent 只准备底稿，**不代提审、不代填真实值、不代勾**（AGENTS.md §7）。
> 真实值纪律：本文件只保留 `{{…}}` 占位符；真实对外名称、联系方式、审核邀请码、版本号**只填在微信后台或随附材料里，不进仓库**。
> 替换规则：①只替换 `{{…}}`；②不添加本文件没有的承诺；③后台上限以实际字段为准，超长时用 §2.2 简版或 §4 简版备注。
> 依据：`docs/delivery/V4_REVIEW_MATERIALS.md` §3 模板、`docs/privacy/隐私保护指引.md`（定稿候选 v1.3）、`docs/contract/V4_CONTRACT.md` §11、`docs/contract/V4_DECISIONS.md`（D13/D36/D57）、`app.json`、`STATE.md` §4 #12/#14/#17。
> 配套：`00_材料包总览与使用顺序.md`（材料索引）、`02_审核截图清单与图注.md`（截图清单与图注，图注可直接用于补充材料）、`03_隐私声明对照表.md`、`04_类目备案与业务说明.md`、`05_提审操作步骤与证据归档.md`；图片见 `images/screenshots/` 与 `images/diagrams/`。

## 3. 完整审核说明（可直接粘贴）

> 使用提示：字段短时保留"三段路径的第一步 + 能力边界 + 联系方式"，把完整版放补充材料附件；**不得删减成与实现不符的表述**。

### 3.1 完整版

```text
【小程序名称】{{对外名称}}｜体验版本 {{版本号}}
【一句话说明】本小程序面向在校学生，提供校园快递代取的下单、接单与取件信息整理；不涉及任何金钱交易，全链路没有资金往来或账目字段。

【体验路径一 · 顾客（审核员本人微信号即可，无需密码）】
1. 打开小程序，先阅读隐私政策并同意（点"暂不同意"会停在启动页，可再次查看并同意，不反复纠缠）。
2. 身份选择页点「我是顾客」→ 完善昵称（必填，可一键取微信昵称或手填，≤20 字）与头像（可选；拒绝后用默认头像，不阻断）→ 填苑/楼栋/宿舍号（手机尾号可留空）→ 获得顾客编号。
3. 下单（四步同页）：取件码截图可选（每单 0~10 张，来源为相册/拍照/聊天；也可完全不传截图，直接手填站点与取件码）→ 核对识别结果（可修改、可手填）→ 选服务类型与预约时间 → 提交。
4. 订单详情可看进度与事件时间线、双方编号、留言、取消、确认送达；页面没有任何账目或资金区域。
5. 取件清单页：除本人进行中订单外，还有「我的取件码」——顾客自己手动粘贴多个码或在本机识别截图添加、勾选"我已取到"、复制、删除、一键清空；不建单、不绑定，只存在这台手机。
6. 「我的」可查资料与编号、消息中心、帮助页（隐私政策/用户协议全文）、解绑与注销入口；注销时有进行中订单会被拦截并提示先处理。

【体验路径二 · 兼职（凭本条说明随附的一次性审核邀请码）】
1. 身份选择页点「我是兼职」→ 输入审核体验邀请码 {{审核邀请码}} → 填写昵称（头像可选）→ 至少启用一个服务类型、选择苑范围、打开接单开关。
2. 工作台按 全部／待接单／待取件／已取件／已送达／需查明／异常／已完结 筛选；可复制汇总（只到苑和栋，便于发到顾客群）。
3. 取件清单分两阶段：待取件按站点列出待取件订单的取件码/柜号/尾号（只读，可复制）；待送达按苑→栋→楼层列出已取件待送达订单，可批量送达。
4. 可「代客下单」为新顾客下单（无需绑定），随后接单→已取件→送达，单机即可完成完整履约。
5. 兼职端不提供绑定顾客入口（绑定只能由顾客发起）；无"分享到朋友圈"；转发卡片为固定中性封面、不含业务值。

【体验路径三 · 开发者后台（仅运营者白名单账号）】
1. 只有运营者白名单微信号打开小程序会被自动分流到开发者总览；普通用户没有任何后台入口，也不能自助注册或申请。
2. 账号切换：真实账号只能只读查看（顶部黄条，写入会被服务端拒绝并留审计）；测试账号是后台合成账号（顶部蓝条 + 每页 TEST 角标，只能写测试数据，不计入统计、不进真实用户列表）。这里的"切换账号"不是切换微信登录账号（平台不支持切换登录的微信账号）。
3. 识别失败复核：用一张识别失败图（遮挡/乱码）走一次识别 → 复核页可临时查看原图（每次查看留审计）+ 去敏文字 + AI 结果 → 补录站点/取件码或忽略。
4. 后台默认脱敏（不展示头像、昵称脱敏、取件码打码、宿舍只到苑和楼栋）；查看完整数据需走只读视角并留审计。后台演示以随附录屏/截图为准。

【与审核相关的能力边界（如实说明，不夸大）】
- 取件码截图不是必填：可以完全不上传截图，直接手填站点与取件码提交（订单显示"无截图·手填"；这类订单不进入识别链路、不产生截图数据）。
- 头像可拒绝：拒绝后为默认头像，不影响下单、接单或资料完成；头像只在当前绑定关系内对对方可见，后台不展示头像。
- 智能识别兜底：仅当截图识别站点/取件码失败时，才把「去敏后的文字」（不含原图、不含微信账号标识、不含联系方式、不含头像昵称）发送第三方 AI 服务（DeepSeek）做辅助识别；原图不发送给第三方，仅进入开发者复核队列（临时查看、逐次审计、默认 30 天删除）；开关关闭、超限或服务不可用时自动降级为手填，不阻断下单。
- 本机取件码清单只存在顾客本人手机：不上传、不共享、不进入服务端或日志或通知或分享卡片；兼职端与开发者后台（含只读视角）均不可见；换设备或清缓存即丢失，可随时一键清空。
- 分享与朋友圈：普通页面可转发给朋友（固定中性封面、不含业务值）；朋友圈入口只在身份选择/顾客首页/帮助三个页面提供，平台对朋友圈能力有基础库与机型限制，以实际设备为准，不承诺所有设备可用。

【联系方式】{{联系方式}}
【随附材料】①顾客侧操作录屏与截图 ②兼职侧操作录屏 ③开发者后台只读与测试会话、识别失败复核截图 ④微信后台隐私声明勾选截图 ⑤类目与备案截图 ⑥示意图 4 张（材料索引/体验路径/隐私数据流/零金额口径）
```
