# PRIVACY · 数据与隐私口径（`docs/PRIVACY.md`）
> 触发来源：V6 契约的**条件文档**（D3/D4 字段触发）。本文件是"我们收了什么、放哪、谁能看到"的**唯一出处**。
> 事实源：`docs/registry/DATA_DICT.md`（字段与敏感度）、`AGENTS.md §8`（卫生）、`docs/decisions/STACK_2026-09-23_沿用v1_A案.md`（选型）。

## §1 一句话
本应用替**单个学生兼职**管理他自己的代取台账，**所有数据只存在这台手机上**：无后端、无云、无网络请求、无第三方 SDK。
⇒ 数据不离开用户设备；**我们（开发者）看不到任何一条记录**。

## §2 D3 字段清单（能定位到人的值 —— 与 `DATA_DICT.md` 敏感度列逐条对应）
| 位置 | 字段 | 含义 |
| :-- | :-- | :-- |
| `Customer` | `building` / `dorm` | 楼栋与宿舍号（能定位到具体房间） |
| `Customer` | `name` | 称呼（可能是真名/昵称） |
| `Customer` | `note` | 备注（自由文本，**禁止**把取件码或会话标识写进去） |
| `Customer` | `chatRoomId` | 会话键：自 `pick_friend` 起存**本地摘要**（不可逆），**不再存平台原值**；保守仍按 D3 对待 |
| `Parcel` | `pickupCode` | 取件码（**能冒领** ⇒ 屏上、日志、文案都不回显） |
| `Parcel` | `trackingTail` | 运单后 5 位（可用于查件，同样不回显） |

**D4：本项目没有**（无密码、无 token、无支付、无证件号）。`id` / 时间戳 / 状态等为 **D2**；`stationName`、`lockerNo`、`schemaVersion` 为 **D1**。

## §3 数据的进出与留存
- **只存本机**：`wx.setStorageSync` 单键 `ex_college_v2.store`；不跨设备、无云端副本、无备份（v1 已知风险原样继承）。
- **识别原文（截图里的文字）不落盘**：只进内存与当前页面显示，不写日志、不联网。
- **会话标识**：平台原值只活在内存（内存桥，**消费一次即清**），落库的是**本地摘要**；不进 URL query、不进日志、不进备注。
- **⛔ v1 的键 `ex_college.store` 禁止读写**（同一个 `appid` ⇒ 同命名空间，动它 = 删真实数据）。

## §4 授权与平台侧
- 用到的系统授权：**相册**（选图）与**摄像头**（拍照）。两道门禁**各自独立**，任一道没授权就只降级为"手工填写"，**不阻断录入**。
- 隐私接口：相册/摄像头相关调用前经 `utils/privacy.js` 检查并给出人话原因（`PRIVACY_DENIED` / `PRIVACY_DENIED_CAMERA`）。
- 微信后台的《用户隐私保护指引》**必须如实声明**收集的信息类型（相册、摄像头、本地存储）；本项目不收集"上传类"信息。
  ⚠️ **待办且未验证**：v2 的后台声明是否已按本文件口径填写，尚未核对（v1 的填写口径参照 `../expresseage_college/docs/BEIAN-填写口径.md`，v1 已冻结只读）。
  ⇒ **用户版草案已出（2026-09-25 · 卡 52）**：[`privacy/隐私保护指引.md`](privacy/隐私保护指引.md)（**对用户**口径，改写自 v1 成品；本文件是**对开发者**口径，两者分工不同）+ [`privacy/发布前填写清单.md`](privacy/发布前填写清单.md)（后台逐项怎么填 + ⚠️ **相册与摄像头是两个隐私类型、必须各自声明** —— `utils/privacy.js` 里记着两条真机实测：`chooseMedia:fail api scope is not declared…` 与 VisionKit `errno=112`）。⛔ 后台填写本身属**人执行**；草案里 `【待你确认】` 处未填完之前，TD-020 不算清。

## §5 用户权利（怎么查、怎么改、怎么删）
- **查**：档案页可见全部档案；记录页可见全部快递记录（含已取件区）。
- **改**：档案页浮层与录入页均可改；改动即写本机库。
- **删**：目前只有**软删**（写 `deletedAt` + 同批 `deleteBatch`，不物理删除）。**清库/物理删除属不可委托清单，只能人执行**（AGENTS §9）。
- **导出 / 备份**：**目前没有**（SCOPE W9：不跨设备、不备份）⇒ 这是已知缺口；将来做导出，走 20/21 卡立项，并把新字段登记回 `DATA_DICT.md`。

## §6 越界红线（改这条要走 22 卡 + 人批准）
1. 让数据离开设备（后端 / 云 / 统计 SDK / 日志上报）——与选型决策卡正面冲突。
2. 把 D3 值写进自由文本（`note`）、日志、URL、或任何上屏文案（只允许指纹）。
3. 引入新的系统权限或新的信息类型（必须先改本文件与后台声明，再谈代码）。
