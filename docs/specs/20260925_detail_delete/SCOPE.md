## §2 Won't（本期不做 + 为什么）
- **W1 归档分区**：用户只撤了"左滑删除"，归档分区（W2）仍不做——它是另一条动线（完成/归档）、需要新字段与新判据。
- **W2 批量选择删除**：多选 + 批量真删会让"不可逆"的爆炸半径变大；本期只做单条。
- **W3 彻底删除快递单条**：回收站只到"档案"粒度（单条快递的真删另开卡；它与批次语义纠缠）。
- **W4 导出/备份**：与 STACK 决策卡"数据只存本机、不备份"冲突（也正是强确认文案要写明的事实）。
- **W5 撤销吐司（undo toast）**：小程序没有原生长时 toast；软删已可从回收站恢复，够用。
