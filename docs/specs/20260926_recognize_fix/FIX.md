### 13.2 代码里有一条会让"图没解出来"被说成"图里没文字"的路

`buildCanvasFrame` 的旧算式：`scale = min(1, 1440 / max(image.width, image.height))`。

- 某些来源的图（**聊天选图**里的 HEIC / 无扩展名文件等），`createImage()` 的 `image.width/height` 会是 **0**；
- 此时 `max(0,0) = 0 ⇒ 1440/0 = Infinity ⇒ scale = 1`，于是 `width = max(1, round(0×1)) = 1`、`height = 1`
  ⇒ **把 1×1 的一个像素送进 OCR**；
- VisionKit 对一个像素**必然"认不出文字"** ⇒ 回收到的就是 `NO_TEXT`，屏上讲"图里没文字"，
  **而真相是"这张图我们根本没解出来"** —— 与用户"次次失败"的读数完全吻合（它是确定性的）。

这条正是本项目最讨厌的一类：**读数与事实相反**（比报错更难查）。
