## 4. 与既有裁决的关系（留痕，⛔ 不许静默覆盖）

- **反转**：`docs/specs/20260923_chat_pick/DESIGN.md §5`「多张串行流水线（v1 `pickqueue.js`）判为不搬」⇒ 本件取代。
