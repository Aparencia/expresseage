# 历史归档索引（docs/archive/README.md）

> **性质**：`docs/archive/` 的索引与归档规则。归档文档**只保留历史价值**：不作为现行口径、不作为验收证据、不参与发布判断。
> **建立**：2026-10-31 文档结构重整（原 `docs/research/`、`docs/reviews/`、`docs/V4_INTERIM_OVERVIEW.md` 迁入）。
> **现行入口**：文档总览见 [`docs/README.md`](../README.md)；口径见 [`docs/contract/V4_CONTRACT.md`](../contract/V4_CONTRACT.md)；状态见根 `STATE.md`；欠账见 [`docs/governance/V4_TECH_DEBT.md`](../governance/V4_TECH_DEBT.md)。

## 归档规则

1. **留档位置**：历史文档一律放 `docs/archive/`（**不移出 `docs/`**）——移出 `docs/` 会同时退出 `check-docs` 与零金额扫描覆盖，属门禁假绿，禁止。
2. **顶部标注**：归档文档应在标题下注明「已归档 + 日期 + 现行口径去哪看」；未标注者以本索引为准。
3. **引用改写**：结构重整时已对归档文档内的文档路径做统一改写（旧路径 → `docs/` 新路径）；但文中的**行号、提交哈希、当时读数**仍是历史快照，追溯以 `git log --follow` 与原提交为准。
4. **不作为证据**：历史审查结论、调研结论、历史门禁读数不得用于「当前已完成」的论证；当前证据以 `STATE.md` §6 与 `check.ps1` 真实输出为准。
5. **新增归档**：需要归档时新建到对应子目录并在本文件登记（来源、日期、结论一句话、时效）。
