# 2026-10-22 · cleanup 域无测试 = 全域运行必崩且无人知道

- 现象：新增 `selftest-cleanup` 首次运行即 `assertCollection is not a function`——cleanup 云函数的每一次真实执行都会 TypeError，但此前批 1~7 从未有测试覆盖该部署单元，门禁全绿。
- 根因：`cloudfunctions/cleanup/db/dao.js` 从 `../shared/collections` 解构了不存在的导出（api 侧存在该键，cleanup 侧副本没有）；该部署单元与 api 不共享 require 图，副本漂移无人校验。
- 教训：**"没有测试覆盖的部署单元 = 未验证的代码"**；部署单元级副本（cleanup/api 各自 shared）必须有测试直接 require 该单元入口，不能只测 api。定时任务的价值在"到期动作"，没有时间旅行测试就只剩静态可见。
- 落地：新增 `cleanup/db/collections.js`（同形校验）+ `cleanup/run.js`（可注入执行器）；`selftest-cleanup` 183 断言以注入 `now` 做「阈值前不动/阈值后生效」时间旅行 + 重跑幂等 + 失败隔离 + 不变量；变异电池 2 组首红（180→90 天、删过期审计）。
