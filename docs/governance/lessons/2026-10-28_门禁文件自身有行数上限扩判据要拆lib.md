# 2026-10-28 · 门禁文件自身有行数上限：扩判据要拆 tools/lib

- 现象：给 `tools/check.js` 追加 #33（分享卡口中性）后，`check.js` 变成 1046 行，**门禁 #18（tools/*.js ≤1000）自己判红**——门禁把自己的扩写卡住了。
- 根因：判据实现体直接写进 `check.js`，而不是像既有 `check-functions` 那样放 `tools/lib/`；`check.js` 已接近 1000 行预算。
- 教训：给门禁加判据前先算行数预算；实现体放 `tools/lib/check-*.js`，`check.js` 只保留 `check(n, 标题, 说明, () => require('./lib/xxx').run())` 一行。
- 落地：#33 抽到 `tools/lib/check-share.js`（清单再抽 `tools/lib/share-pages.js` 供门禁/测试共用）；`check.js` 995 行；判据说明回写 ENGINEERING §8.2。
