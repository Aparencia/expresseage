# 改测试文件尾部时丢 `module.exports = { EXPECTED_ASSERTIONS, register }` → 整套静默漏跑

**现象**：`check.ps1` 第 4 步报「运行 39 套；失败 1 套」，日志只有一条 `[FAIL] selftest-xxx · 非 register 聚合形态（缺 register/EXPECTED_ASSERTIONS）`；单跑该套 `node tools/selftest-xxx.js` 却全绿。

**根因**：在 `tools/selftest-*.js` 末尾插入新断言段时，把「`}` 换行 + `module.exports = {…}`」整体当作 old_string，替换后只补回了 `}`，导出整行丢失。`require.main` 分支不依赖导出，所以单跑不报错；聚合器 `tools/selftest.js` 拿不到 `register/EXPECTED_ASSERTIONS`，就静默把该套从总数里漏掉（总数还显示 39 套，但少跑一套）。

**判据**：改测试尾部后至少跑一次 `node tools/selftest.js`（聚合），不要只跑单套；看到「非 register 聚合形态」直接查文件尾导出。

**修法**：补回 `module.exports = { EXPECTED_ASSERTIONS, register };`，确认聚合从 38/39 回到 39/39 且断言总数等于该套 `EXPECTED_ASSERTIONS`。
